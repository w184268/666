WatchTube 使用指南

孩子在手表上问一句，自动收到一段讲这件事的科普视频。这份指南按「照着点」的方式写，不需要编程基础。

孩子在手表上说话/打字 　↓ 小天才 App 弹出通知 手机上的桥接程序 （本指南要装的东西） 　↓ 通过局域网发给服务端 服务端：理解问题 → 搜 B站 → 安全过滤 → 剪前 60 秒 → 压成 3MB 　↓ 手机取回视频 → 写进相册 → 自动/一键发回微聊 　↓ 🎉 孩子抬起手腕就能看了

先搞清楚：这套东西是两个部分

必须同时具备，缺一不可：

部分跑在哪干什么
服务端（大脑）你家的电脑 / 小主机 / NAS理解问题、搜视频、压制
手机端（手脚）你的安卓手机抓孩子的消息、把视频发回手表
服务端那台电脑要开着，一般用家里的台式机或常年不关的小主机就行。

三选一：你的情况适合哪条路

推荐 · 不用装任何软件

A. GitHub 网页自动编 APK

把项目传到 GitHub，它自带的构建机帮你编译成 APK，直接下载。全程网页操作，约 10 分钟。

有电脑当选

B. 用 Android Studio 编译

装 Development 环境（约 1GB），然后点一下运行就装到手机。适合以后想自己改代码。

只有手机 · 半自动

C. 用 Tasker 免安装 APK

装个 Tasker 配几条规则即可，但最后一步要手动点几下发送。

第一部分：让服务端先跑起来

不管选哪条手机路线，这部分都要做。

第 1 步：装两个东西

  • Python 3.10+：python.org 下载安装，装的时候务必勾选 "Add Python to PATH"
  • ffmpeg：负责压制视频
    • Windows：去 gyan.dev/ffmpeg/builds 下载 essentials 版，解压后把里面的 bin 文件夹路径加到系统 PATH
    • Mac：brew install ffmpeg
    • Ubuntu：sudo apt install ffmpeg

验证装好没：终端里输入 ffmpeg -version，出版本号就成。

第 2 步：改配置

1 进入项目里的 server 文件夹，把 config.example.yaml 复制一份，改名 config.yaml
2 用记事本/VS Code 打开 config.yaml，改这两处： 
server:
  public_base_url: "http://192.168.1.10:8787"   ← 改成你自己电脑的局域网IP
  bridge_key: "自己起一串密码"                   ← 手机App里要填一样的

understanding:
  api_key: "sk-xxxx"                            ← 留空也能跑（会自动降级）
3 查自己电脑的局域网 IP：
  • Windows：打开命令提示符，输入 ipconfig，找「IPv4 地址」
  • Mac/Linux：终端输入 ip addr 或 ifconfig

第 3 步：启动

Windows 双击 run.bat；Mac/Linux 终端执行 ./run.sh。

看到 "WatchTube 已启动" 就成了。浏览器打开 http://你的IP:8787 是家长看板——孩子问了什么、选了哪条视频、里面的处理日志，全在这。

第 4 步：不用手机，先自测一遍

python3 ../tools/selftest.py "恐龙为什么会灭绝啊"

看到「🎉 全链路跑通」说明服务端这边的活已经能干了。

第二部分：手机端

路线 A · GitHub 网页编 APK（推荐）

原理：GitHub 免费提供云端编译机，你把代码传上去，它帮你编好 APK 让你下载。

1 打开 github.com 注册/登录（免费的），点右上角 + → New repository
2 仓库名随便填（比如 watchtube），选 Public（公开仓库的构建额度完全免费），勾选 Add a README，点创建
3 在仓库首页点绿色的 Code 按钮旁的 Add file → Upload files
4 把整个 watchtube 文件夹拖进网页上传框（请用 Chrome 或 Edge 浏览器，Safari 不支持拖文件夹）
务必包含里面的 .github 和 android 两个目录，一共 43 个文件。用 Chrome 或 Edge，Safari 拖文件夹会漏东西。
5 上传后扫一眼文件列表里有没有 .github/workflows/build-apk.yml（隐藏目录在个别浏览器上会被跳过）。
如果没看到，就在仓库首页右边点 Code 复制地址，然后在本机一次性跑下面三条命令上传（更稳）： 
git clone https://github.com/你的用户名/你的仓库名.git
cp -r watchtube/* 你的仓库名/ && cd 你的仓库名
git add -A && git commit -m "init" && git push
6 拉到页面底部，点绿色的 Commit changes
7 点页面上方的 Actions 标签，会看到一个叫「构建 APK」的任务在转圈，等 5–10 分钟
Actions 里如果空空如也 —— 说明 .github 没传上来，回到第 5 步用命令重传。
8 变绿打勾 ✅ 后点进去，拉到页面底部 Artifacts 区，点 watchbridge-debug-apk 下载
9 解压 zip，得到 app-debug.apk，传到手机安装（微信/QQ 传给自己，或用数据线）
⚠️ 如果你已经把填了真实密码的 config.yaml 传上去了 —— 公开仓库里别放真实密码，APK 里不含它，不影响使用，但建议把 server/config.yaml 删掉再传。
💡 这一步我无法替你实跑（沙箱里连不上 Google 的 SDK 下载站），所以万一 Actions 报红：把报错信息发我，我来改。这是很标准的构建流程，成功率很高。

路线 B · 用 Android Studio 编译

1 下载安装 developer.android.com/studio（一路下一步即可）
2 打开时选 Open，选中项目里的 android 文件夹
3 右下角提示 Trust Project 就点同意；然后等它自己下载依赖，第一次要 5–10 分钟（看网速），进度条在下方
4 手机：设置 → 关于手机 → 连点"版本号"7 次 打开开发者模式 → 返回 → 开发者选项里开 USB 调试
5 数据线连电脑，手机上允许 USB 调试。屏幕右上角设备列表里会出现你的手机
6 点绿色三角 ▶️ 运行，手机会自动装上 WatchBridge

路线 C · Tasker 免 APK（最后一步手动）

适合：不想折腾编译，愿意每次手动发出去。

1 手机装 Tasker + AutoNotification 两个 App
2 Tasker 里新建 Profile：Event → Plugin → AutoNotification → Intercept，Apps 选小天才，勾选 Include Notification Text
3 关联任务里加 HTTP Request 动作： 
Method:  POST
URL:     http://你的电脑IP:8787/api/v1/ingest
Headers: Content-Type:application/json
Body:    {"sender":"孩子","text":"%antext"}
4 再建一个定时 Profile（每 2 分钟），用 HTTP Request 取件：http://你的IP:8787/api/v1/outbox，把返回的 video_url 下载下来存到相册
5 收到通知后手动操作：打开小天才 App → 微聊 → 发送相册里刚下载的视频

第三部分：装完 App 后配置四件事

1 打开 WatchBridge，填服务端地址（http://你的电脑IP:8787）和API Key（你在 config.yaml 里写的那个），点保存
2 点 测试连接，看到「连通正常」就是通了 —— 通不了的话检查两端是不是在同一个 WiFi
3 点 开启消息监听权限，在系统设置里勾选 WatchBridge
点 加入电池优化白名单（不加的话半夜会被系统杀掉）
4 想要全自动的话，点 开启无障碍，找到「手表视频投递」打开
建议先开着「干跑模式」跑一次：它会把小天才界面上的按钮全部记到日志里但不真点，对着日志把发送脚本调准，再关掉干跑。

验收：让孩子问一句试试

让孩子在手表上说「为什么天是蓝色的」，30 秒左右：

  1. App 日志里应看到「捕获消息」→「已提交服务端」
  2. 大约 40 秒后看到「下载完成」→「投递完成」
  3. 孩子手表上收到一段 60 秒的视频
  4. 家长看板同步显示这条记录

常见问题

症状大概率原因
孩子发消息，服务端毫无反应通知监听没授权；或同一句话 8 秒内重复被去重了
App 一直显示"取件失败"public_base_url 填错了；手机和电脑不在同一网络
服务端报编码器错误ffmpeg 没装好，或版本太老
自动发送点了乱七八糟的地方脚本按钮对不上，开干跑模式看日志调
隔天不工作了被省电策略杀了，加白名单（各路径见 README）
孩子收不到视频你的手表型号不支持微聊视频 —— 先用手在小天才 App 里给孩子发个视频试试。
不行就把 reply_mode 改成 audio（语音讲解）
🎯 一句话总结：服务端跑在家里电脑（自测脚本验证通过即可），手机上用 GitHub 编出来的 APK 装上授权， 然后让孩子在手表上问一个问题试试。有报错随时把日志贴出来。
